# InEK DatenBrowser: original-export redistribution review

Reviewed on 17 November 2026 for the two private dysphagia manuscript repositories. Scope: the current **datenbrowser.inek.org** service and the downloaded research-result Excel workbooks. This is a documented rights-clearance assessment, not a grant of rights by InEK.

## Decision

**Do not add original Excel exports to either repository at this stage.** Explicit permission to redistribute these workbooks, including through a private GitHub repository and a later public repository, has not been established. This is an unresolved permission question, not a finding that every redistribution is legally prohibited. Both repositories must remain private; no visibility change or public release is authorized by this review.

## Primary sources and documented observations

1. [Official InEK DatenBrowser manual](https://datenbrowser.inek.org/assets/manual/InekDatenBrowser.pdf), version **1 September 2026**, sections 1.1–1.2 (printed pages 6–7), 3.4 (61–62), and 3.6 (65). The current PDF was retrieved directly from InEK; its cover, full terms and export section were checked.

   The manual permits local Excel export and further investigation. Section 3.6 says: “Die Excel-Mappe können Sie für weitere Untersuchungen der Ergebnisse nutzen.” Terms I.1 concern research in submitted datasets. I.2 restricts program modification; I.3 restricts transfer of the browser, wholly or partly, including commercial exploitation; I.4 prohibits automated browser use and data retrieval outside the browser. Rights in the browser remain with InEK. No separate workbook-redistribution, attribution or altered-data licence was identified. The present text does not contain the older product's non-commercial-research-only wording. Section 3.4 withholds queries below five cases and detailed diagnosis/procedure/DRG rows with counts 1–4; the Info distribution is complete when the query itself meets the threshold.

2. [Official current product page](https://www.g-drg.de/datenlieferung-gem.-21-khentgg/inek-datenbrowser). It identifies the service, scientific-use purpose, covered deliveries and official manual. It is not an open-data redistribution licence. Its brief suppression description refers to fewer than four results; the more specific, dated manual specifies the five-case threshold. Do not silently substitute the landing-page wording for the manual and observed exports.

3. [Official InEK imprint](https://www.g-drg.de/impressum), copyright paragraph. It requires prior written InEK consent for reproduction of data and information on its webpages. Whether that general website statement directly governs the exported research workbooks is not resolved here; it does not provide affirmative permission to redistribute them. The imprint gives the official contact **info@inek-drg.de**. No message has been sent.

## Interpretation and packaging consequences

| Question | Assessment for these repositories |
| --- | --- |
| Original Excel files, private repository | Permission not established. A private repository still creates hosted copies and may share them with collaborators; privacy does not settle third-party rights. Keep exports local. |
| Original Excel files, later public release | Obtain an explicit InEK clarification covering these particular exported tables before adding them. No current publication permission is inferred. |
| Non-commercial versus commercial | Do not import the 2014 Begleitforschungsbrowser restriction; equally, do not infer unrestricted commercial reuse of current exports. Ask InEK about the intended research/publication/repository use. |
| Attribution | Preserve InEK attribution, dataset delivery/snapshot, access date, exact selections, original filenames and hashes as scientific provenance. Attribution alone does not establish permission. |
| Changed or derived data | Keep the originals unchanged locally and label transformations as author analyses. Do not present recalculated results as official InEK tables or apply an open licence to InEK originals. |
| Suppressed and small cells | Retain unknown status; do not restore absent rows as zero. Continue to omit detailed sparse reconstructed cells from publication packages. This project rule is distinct from a redistribution licence. |

The current repository package may contain the authors' scripts, documented query definitions, source checksums and disclosure-controlled aggregate analysis outputs. The source workbooks and full internal cell JSONs remain excluded. Readers seeking the source aggregates should use their own InEK access and the documented selections, subject to the service terms; the supplied scripts analyse local files and do not download data automatically.

## Scope and unresolved points

The separate [2014 G-DRG-Begleitforschungsbrowser agreement](https://browser.inek.org/agreement), old downloadable G-DRG browsers, the InEK Datenportal and report-browser terms were **not** treated as licences for this service. The current web terms route could not be rendered through the background web reader; the dated current official manual contains the full terms used above. No stronger export-specific permission was found in targeted searches of InEK's official domains.

Before adding originals, request written clarification of: (1) unchanged Excel uploads to a private collaboration repository, (2) later public archival redistribution, (3) publication of adapted tables and derived results, (4) required attribution/change notices, (5) commercial/non-commercial scope, and (6) disclosure-control conditions. Any later permission should be retained with its exact scope and date. This review does not contact InEK, alter repository visibility or grant a publication licence.
