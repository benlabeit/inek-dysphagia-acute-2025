# Literature and provenance materials

The complete 66-record PubMed author inventory, screening decisions, bibliographic metadata, search queries and pagination checks are included. The search is a supplementary author-focused narrative search, not an exhaustive systematic dysphagia review. The shared inventory is retained in both repositories; acute and rehabilitation inclusion decisions remain distinct.

Source EFetch XML and the full local PubMed retrieval JSON containing abstracts are retained only in the local verification files and are not redistributed. `xml_source` metadata identifies those local audit files; it is not a link to a bundled XML file. The screened JSON files contain bibliographic metadata and author assessments, without full abstracts. PubMed and DOI links identify the original sources.

The affiliation assessment is a source-verification record; it does not substitute for author confirmation of current affiliations, author contributions, funding or conflicts. The OPS memo documents the definition of 1-613 and its interpretation limits. The InEK reuse memo records an unresolved source-workbook redistribution question; no original InEK exports are included.
