# Data availability

This study used aggregate hospital episode data from the InEK DatenBrowser ([https://datenbrowser.inek.org/DRG202601](https://datenbrowser.inek.org/DRG202601)), specifically the “Unterjährige Datenlieferung DRG Januar bis Dezember 2025” (data delivery of 16 January 2026). Registered users can reproduce the source queries through the InEK DatenBrowser under its terms of use. The query definitions, analysis code and aggregate results are available at [https://github.com/benlabeit/inek-dysphagia-acute-2025](https://github.com/benlabeit/inek-dysphagia-acute-2025). The original Excel exports are not redistributed. The authors had no access to patient-level data.

## Source access and redistribution

Original InEK Excel exports are not redistributed because permission for repository redistribution has not been established. This is an unresolved permission question, not a claim that all redistribution is prohibited. Registered users can obtain the source aggregates through the [InEK DatenBrowser](https://datenbrowser.inek.org/) using the documented selections and subject to the service's terms.

The [official manual, version 1 September 2026](https://datenbrowser.inek.org/assets/manual/InekDatenBrowser.pdf), documents Excel export for further analysis in section 3.6 and the service terms in section 1.2. Permission to download and analyse is not treated here as an explicit licence to rehost original workbooks. Terms for the separate 2014 Begleitforschungsbrowser are not substituted for those of the current service.

The repository contains author-written analysis code, query definitions, source filenames and checksums, and disclosure-controlled derived results. It does not include original XLSX workbooks, full parsed source tables or detailed joint-cell JSONs. Source files are retained unchanged outside version control. Scripts operate on local exports; no automated InEK downloader is provided. Derived results are identified as author analyses, with InEK source attribution, rather than official InEK tables. No licence over the InEK source workbooks is granted here.

The original query manifest and the joint two-/three-factor manifests identify the required inputs and checksums. A missing or suppressed source row is not imputed as zero. Published aggregate outputs omit detailed sparse reconstructed cells. These analytical disclosure controls do not themselves settle reuse rights.

Before including source workbooks in either a private or a public repository, obtain an InEK clarification that explicitly covers that distribution, any adapted tables, attribution and change notices, commercial/non-commercial scope, and disclosure-control requirements.
